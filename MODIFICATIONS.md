# SE4030 Secure Software Development — Group Assignment

This repository is a modified fork of an existing open-source project,
created for an academic security assignment. Our work identifies and fixes
distinct security vulnerabilities in the application and adds an OAuth 2.0 /
OpenID Connect based authentication feature.

## Original project

- Repository: https://github.com/SamiurRahmanMukul/Hotel-Room-Booking-System
- Author: Md. Samiur Rahman (Mukul)
- Licence: Apache 2.0
- Last commit of original: September 2025 (before our semester start of 19 June 2026)

## Scope of our work

- Identify and fix 7 distinct security vulnerabilities (see report for full detail)
- Implement an OAuth 2.0 / OpenID Connect based authentication function
- All changes are documented in the report and in this repository's commit history
